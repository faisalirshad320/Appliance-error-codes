Maytag washer error codes: how to read them and what to do next

Last reviewed 2026-10-15 · Maytag washer

What it means

Maytag washers report faults as a two-part code: an F number that names the subsystem and an E number that names the specific fault inside it. F8 E1 is the water fill system reporting a long fill; F9 E1 is the drain system reporting a long drain. A handful of codes are plain words instead, such as LF for long fill, Sd for suds and LoC for control lock. Many Maytag washers have no alphanumeric display at all and signal faults by blinking the cycle indicator lights, which has to be read as a pattern rather than a code. Maytag and Whirlpool build on shared platforms, so a Maytag code list is effectively the Whirlpool one.

Safety first

Unplug the washer at the outlet or switch off its breaker before removing any panel, testing any component or disconnecting any connector. Never bypass the door or lid interlock to get a cycle to run; it is the only thing stopping the drum spinning with the machine open.

Why a Maytag washer shows this code

These are the causes in the order you are most likely to hit them. Work down the list, do not skip to the expensive one.

  1. Water fill and supply faults, the F8 family and LFmost casesThe machine sits there filling slowly or not at all, or stops partway with nothing happening. F8 E1 and LF both mean long fill: it did not reach the water level in time. F8 E2 points at the dispenser. Check both supply valves, the mesh inlet screens and how far the drain hose sits in the standpipe before assuming a part has failed.
  2. Drain faults, the F9 familymost casesWater is standing in the drum at the end of a cycle, or the spin never happens. F9 E1 is a long drain. The first stop is always the drain pump filter behind the lower front panel on front loaders, and the drain hose for kinks and for being shoved too deep into the standpipe on any model.
  3. Door and lid lock faults, the F5 familycommonThe cycle will not start, or the door will not release at the end. The control could not confirm the lock. Check for laundry caught in the opening, then the latch cavity for dried detergent, then the lock assembly itself, which is a known wear item on Maytag top loaders.
  4. Detergent and maintenance notices that are not faults at allcommonThe machine is still working and the message is advisory. Sd or Sud means excess suds and the washer is extending the rinse to deal with it. CL is the reminder to run the Clean Washer cycle. LoC or LC is the control lock. rL means take the laundry out of a cleaning cycle. None of these need a technician or a part.
  5. Motor, drive and load distribution faults, the F7 family and uLoccasionalThe drum will not turn, turns in one direction only, or the machine cannot get up to spin speed and keeps redistributing. uL means an unbalanced load, which is a single heavy item or a load wrapped around the agitator rather than a broken part. F7 codes point at the motor control, the motor itself, or on top loaders the shifter and drive assembly.
  6. Control, user interface and communication faults, the F1, F2 and F6 familiesoccasionalButtons do nothing, the display behaves oddly, or several unrelated symptoms appear at once. F6 codes mean the main control and the user interface board have stopped talking, which is often a connector rather than a board. These are the codes where parts cost real money, so check the harness connections before replacing anything.
  7. Sensor faults, the F3 familyrareThe machine reports a level or temperature it cannot be reading correctly, such as calling a fill fault while the drum visibly fills. On water level faults, suspect the small clear air hose that runs from a port low on the outer tub up to the pressure sensor, which blocks with soap scum or splits at the ends long before the sensor itself fails.

Fix it step by step

  1. Write the code down exactly, both halves of it

    Photograph the display before you touch anything. F8 E1 and F8 E2 are different faults in the same system and lead to different work, and a code that scrolls can be gone before you have found a pen. If the display alternates between two codes, note both and the order. If it shows a plain word such as LF or Sud rather than an F and E pair, note that too, because those sit outside the numbered system.

    2 minTools: Phone camera

  2. Cut the power for five minutes and see whether it comes back

    Unplug the machine at the outlet or switch its breaker off, leave it a full five minutes so the control board loses its residual charge, then restore power and run a Rinse and Spin. A code that never returns was a one-off glitch. A code that comes straight back is a real fault and names the subsystem that has it. Five minutes matters; a quick flick of the switch often leaves the stored fault in place.

    7 min

  3. Use the F number to pick the system, then check the mechanical things first

    Broadly, F5 is the door and lid lock, F7 is the motor and drive, F8 is water fill and the dispenser, and F9 is the drain, while F1, F2 and F6 cover the control boards and the link between them. Every one of those families has a free mechanical check that comes before any part: valves and inlet screens for a fill code, the pump filter and drain hose for a drain code, the latch cavity and the striker for a lock code. Do those before you buy anything.

    25 minTools: Flashlight, Phillips #2 screwdriver

    Unplug the machine before opening any panel or reaching into the pump housing.

  4. If there is no display, read the lights instead

    Plenty of Maytag top loaders have a dial and a column of indicator lights rather than a readout, and those machines report faults by blinking Sensing, Wash, Rinse, Spin, Done and Lid Lock in patterns. A blinking Lid Lock light on its own usually means the lid lock circuit, which is the light-only version of an F5 code. To get anything more specific you have to enter the service diagnostic mode and read a blink count, where the number of flashes in the first group gives the F number and the second group gives the E number.

    15 min

  5. Find the service sheet that came with your machine

    Every Maytag washer ships with a folded service sheet hidden inside it: usually tucked into the console on top loaders, or taped to the underside of the top panel or inside the lower front access panel on front loaders. It carries the exact code list for your model, the diagnostic entry sequence for that platform, and the component test values. That sheet beats any general list, including this page, because the dial sequences and some code meanings genuinely differ between platforms.

    10 minTools: Flashlight, Phillips #2 screwdriver

    Unplug the machine before lifting the top panel or opening the console.

  6. Check the obvious user causes before you order a part

    Before concluding that a code means a failed component, rule out the things that produce the same symptom for free: too much detergent, a load of towels all on one side of the drum, a drain hose pushed too far into the standpipe, a supply valve left shut after plumbing work, and a single item caught in the door seal. These account for a large share of the codes people pay to have diagnosed.

    15 min

  7. Decide whether this is a part or a technician

    Pump filters, inlet screens, drain hoses, detergent dosing and lid locks are all reasonable home jobs with a screwdriver and a nut driver. Motor control boards, main control boards and anything needing live voltage measurements inside a wet appliance are not. If the code points at F1, F2, F6 or F7 and the free checks have not moved it, get a quote before buying anything, because the parts on those families routinely cost more than half the price of a new machine.

    10 min

How to reset it

The general reset for any Maytag washer code is to cancel the cycle with the Power button, then unplug the machine or switch off its breaker for a full five minutes before restoring power. That clears stored fault states that otherwise keep displaying after the real problem is fixed. Test with a Rinse and Spin rather than a full cycle so you find out in two minutes rather than fifty. A reset is a way of confirming whether a fault is live, not a repair: a code that returns is telling you something real.

It still shows the code

If a code keeps coming back after a power cut and the obvious mechanical checks, the next move depends on how specific your display is. On a machine with a full readout, note whether the E number changes between attempts. A code family that stays fixed, say F9 E1 every time, is a genuine hardware fault in that system and is worth working through properly. A machine throwing different families on different cycles, say a fill code one day and a motor code the next, is usually reporting a power or control problem rather than four separate broken parts, and the thing to check is the main wiring harness connectors and the supply to the machine before you replace anything. On a machine with no display, this is the point to enter service diagnostics rather than guessing. The entry sequence is a specific pattern of dial turns and button presses done within a few seconds, and it genuinely differs between platforms, so get it from the service sheet folded inside your own console rather than from a video of someone else's washer. Once you are in, the machine will step through its stored faults as blink patterns and you can count out the F and E numbers. Two sanity checks are worth running before you spend money on any Maytag code. First, confirm the machine has a solid power supply: a washer on a shared circuit with a dryer or a failing outlet produces intermittent control and communication faults that look like a dying board. Second, pull the lower access panel and look for water where it should not be, because a slow leak onto a connector or a control board creates codes across several unrelated families at once. If the code points at the main control board, the motor control board or the user interface board, get a written quote before agreeing to anything. Those parts run from around $150 to well over $300 before labor, and on a washer past eight or nine years old the honest arithmetic often favors replacement.

Differences between models

Maytag and Whirlpool washers are built on shared platforms, so the code systems are effectively the same and a Whirlpool code list will usually answer a Maytag question. Within Maytag, three display types exist and each behaves differently. Machines with a full digital readout show the complete F and E pair. Machines with a short alphanumeric panel tend to show the word codes instead, so you get LF rather than F8 E1 and Sd rather than a number. Machines with just a dial and indicator lights show nothing at all and have to be put into service diagnostics so the fault can be read as a blink count, and the entry sequence for that varies by platform. The exact pairing of E numbers to faults also shifts a little between front load and top load platforms, which is why the service sheet inside your own machine outranks any general list.

When to stop and call someone

Call a technician when the code points at the control boards or the motor, when the free mechanical checks have not shifted it, or when the next diagnostic step needs live voltage measurements inside a wet machine. Call sooner if the washer trips the breaker, smells of burning or has visible water on a connector or board, and stop using it until it has been looked at. Call a plumber instead of an appliance technician if a fill code comes with weak flow from a hose held into a bucket, or if a drain code comes with a standpipe that backs up when anything else in the house drains, because those faults are in the house rather than the machine. For most other codes, the diagnosis is worth more than the repair: ask for a quote on the part before agreeing to the work.

Questions people ask

What do the F and E numbers mean on a Maytag washer?

The F number names the subsystem and the E number names the specific fault inside it. F8 is the water fill system and F8 E1 is a long fill; F9 is the drain system and F9 E1 is a long drain. Reading the F number first tells you which part of the machine to inspect before you worry about the detail.

My Maytag has no display, just flashing lights. How do I get a code?

Those models report faults through the Sensing, Wash, Rinse, Spin, Done and Lid Lock indicators. A lid lock light blinking alone points at the lock circuit. For anything more specific you enter the service diagnostic mode and count blink patterns, where the first group of flashes gives the F number and the second gives the E number.

Where is the service sheet on a Maytag washer?

Folded inside the machine. On top loaders it is usually tucked into the console behind the control panel; on front loaders it is taped under the top panel or inside the lower front access panel. It carries your model's exact code list, the diagnostic entry sequence and the component test values, all of which beat a general list online.

Are Maytag and Whirlpool washer error codes the same?

Essentially yes. Whirlpool owns Maytag and the two share washer platforms, control boards and code systems, so a Whirlpool code list will answer most Maytag questions and vice versa. Amana and some Crosley machines sit on the same platforms too. Where small differences exist, they are between front load and top load designs rather than between the badges.

How do I reset a Maytag washer error code?

Cancel with the Power button, then unplug the washer or switch off its breaker for five minutes before restoring power. That clears the stored fault. Test with a Rinse and Spin instead of a full cycle. A reset only tells you whether the fault is live; if the code comes back, the machine is reporting something real and needs the actual check done.

Which Maytag codes mean nothing is broken?

Several. Sd or Sud is an excess suds notice and the machine handles it by extending the rinse. CL is a reminder to run the Clean Washer cycle. LoC or LC means the control lock is on. rL means take the laundry out of a cleaning cycle. uL is an unbalanced load. All of those are messages about how the machine is being used.

Which Maytag codes are expensive?

The control and motor families. F1, F2 and F6 codes involve the main control board, the user interface board or the link between them, and F7 codes involve motor control. Those parts run from roughly $150 to over $330 before labor. Check the harness connectors and the power supply first, because a loose connector produces the same codes for nothing.

Can I keep using the washer with a code showing?

It depends which one. Suds, clean reminders and unbalanced load messages are safe to work around. Fill, drain and lock codes stop the cycle, so there is nothing to use. Stop entirely and unplug the machine if it trips the breaker, smells hot, or you can see water near any electrical connector or board.
