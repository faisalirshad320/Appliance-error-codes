Miele coffee machine F43: what is actually known about this code

Last reviewed 2026-10-15 · Miele coffee machine

What it means

F43 is not a well documented code on Miele coffee machines. It does not appear in the published fault tables for the coffee range, where the familiar F codes cover water intake, the grinder and the brew unit, and no reliable public source defines it. What is known is that across Miele's other appliance lines, the F4x codes are internal electronics and configuration faults rather than anything an owner maintains, which puts F43 in service territory rather than descaling territory. Do the full power-down reset below and check that the brew unit, drip tray, grounds container and water tank are all properly seated, because a component the machine cannot see produces odd codes. If it returns, book Miele service rather than guessing at parts.

Safety first

A Miele coffee machine contains a mains-voltage heater and a pressurized hot water circuit. Unplug it and let it cool fully before removing or reseating anything, and do not open the cabinet; the serviceable parts on these machines are all reachable from the front or the side door with no tools.

Why a Miele coffee machine shows F43

These are the causes in the order you are most likely to hit them. Work down the list, do not skip to the expensive one.

  1. An internal control or module fault the machine cannot clear itselfmost casesThe code returns immediately or within a cup or two of every power-up, regardless of what you reseat or clean, and the machine will not run a normal brew cycle. A fault that survives a full power-down and a reseat of every removable part is not a user-level problem, whatever it turns out to be called.
  2. A transient glitch that a full power-down clearscommonThe code appeared once, often after a power cut, a surge, a move, or an interrupted cycle. Unplug the machine for several minutes, plug it back in and run a rinse. If it brews normally after that and the code never comes back, it was a glitch, and there is nothing to repair.
  3. A removable component is not seated, so the machine cannot detect itcommonThe drip tray, grounds container, water tank or brew unit went back in slightly off, or a magnet or switch face is wet or coffee-grounds-caked. Take each one out and put it back deliberately until it clicks home. On machines with a removable brew unit, it must be in its home position before it will slide in; forcing it is what breaks them.
  4. A sensor, switch or module inside the machine has failedoccasionalEverything reseats correctly, the resets are clean, and the fault still appears at the same point every time. A fault that is reproducible at a specific moment in the cycle is a failed component rather than a glitch, and a technician can read the machine's own fault log to identify it in minutes.
  5. Configuration mismatch after a board replacement or a service visitoccasionalThe machine was repaired, serviced or had electronics replaced shortly before the code started. On other Miele appliance lines, F43 specifically indicates that the model type has not been programmed or that two modules do not match each other, which is exactly what happens when a replacement board goes in without being configured. That meaning has not been confirmed for the coffee range, but if your machine was recently serviced, tell whoever did it, because reprogramming is a software job and not a new part.

Fix it step by step

  1. Write down exactly what the display shows

    Photograph the screen, including any text above or below the code and any fault number Miele shows alongside it. Miele displays usually pair a code with a short plain-language message, and that message is more useful than the number for working out which part of the machine is unhappy. Note what the machine was doing when it appeared: at power-up, during grinding, during brewing, or at the rinse.

    3 minTools: Phone camera

  2. Do a full power-down reset, not a standby

    Switch the machine off at its own power button, then pull the plug from the wall and leave it out for at least five minutes. Standby is not off: these machines keep their electronics alive and a stored fault will still be there. If it is a built-in model, use the isolating switch in the adjacent cabinet or the breaker. Plug back in and let it run its automatic rinse without interrupting it.

    10 min

    Let the machine cool before handling internal parts. The brew unit and the water path stay hot for some time after use.

  3. Remove and reseat every part the machine has to detect

    With the machine cool and unplugged, take out the drip tray, the grounds container and the water tank. Wipe the contact faces and the recesses they sit in, especially any small magnet or metal tab and the matching spot on the housing, which collects coffee grounds and milk residue. Put each back deliberately until it seats with a click. A tray sitting a few millimeters proud is enough for the machine to decide it is missing.

    10 minTools: Soft cloth

  4. Remove, rinse and refit the brew unit if your model has one

    On models with a removable brew unit, open the side door, press the release and slide it out. Rinse it under warm water with no detergent, let it drain, and check nothing is jammed in the chamber. It must be in its home position to go back in; most have an arrow or markers that have to line up. Slide it in squarely until it latches. Never force it, and never lever it with a tool, because the plastic rails are what fail when people do.

    15 minTools: Soft cloth

    Machine unplugged and cool before removing the brew unit.

  5. Run the machine's own cleaning cycle if it will let you

    If the machine reaches its menu, run the brew unit degrease or clean cycle with the proper Miele tablet, and descale it if it has been asking you to. This will not fix an electronics fault, but it rules out the possibility that the code is downstream of a clogged or seized brew unit, and it costs one tablet. If the machine will not enter its menu at all, skip this and go to the next step.

    25 minTools: Miele cleaning tablet, descaling product specified for your model

  6. Book Miele service with the model and serial number ready

    If the code survives the power-down and the reseat, stop. Get the model and serial number from the rating label, which on most Miele coffee machines is behind the water tank or on the underside. Give Miele the exact code, the exact display message and the point in the cycle it appears. Their machines keep an internal fault log a technician can read directly, which is the fastest and cheapest route to a real diagnosis on a code nobody publishes.

    15 minTools: Phone, model and serial number

How to reset it

Switch off at the machine's own power button, then unplug it at the wall, or use the isolating switch or breaker for a built-in model. Leave it disconnected for at least five minutes, and half an hour if five did not work. Standby does not count: these machines stay powered and keep the stored fault. Plug back in with the water tank full and every removable part seated, let the automatic rinse run through without interrupting it, and then try a single espresso rather than a milk drink, so fewer systems are involved in the test.

It still shows F43

Be straight with yourself about what this code is. Miele publishes fault tables for its coffee machines covering water intake, the grinder, the brew unit and the drainage path, and F43 is not in them. No reliable public source defines it for the coffee range. That means anyone online telling you confidently that F43 is a specific sensor or a specific valve is guessing, and fitting a part on that basis is how people spend two hundred dollars and still have the code. Here is the honest escalation. First, repeat the full power-down, but leave it unplugged for half an hour rather than five minutes, and put the machine back together with the water tank filled and everything seated before you restore power. Some control faults latch until the electronics fully discharge. Second, try it with the grounds container and drip tray removed and then refitted while the machine is powered on, if your model allows, and watch whether the display acknowledges each one. A machine that does not notice a tray going back in has told you which circuit is unhappy. Third, if the machine was serviced, repaired or had electronics replaced in the recent past, phone whoever did that work before you phone anyone else. On other Miele appliance lines F43 means a module has not been programmed with the correct model type, which is precisely the state a replacement board arrives in. That has not been confirmed for coffee machines, but it costs one phone call to check and the fix would be software rather than parts. Fourth, book Miele service. These machines log their own faults internally and a technician reads that log rather than working from the number on the screen, so they will know within minutes what the machine is actually complaining about. Expect $180 to $450 including the call-out, which on a Miele is usually worth it, because the machines run well past a decade and the alternative is a four-figure replacement. What you should not do is buy a part based on a code chart for a Miele dryer, oven or washing machine. Those appliances use the same F numbering and mean different things by it, and that cross-contamination is where most of the bad advice about F43 comes from.

Differences between models

Miele uses F-prefixed codes across its whole appliance range, and the same number means different things on different appliances. F43 is documented on Miele tumble dryers, washing machines and ovens, where it indicates that the model type has not been programmed or that two control modules do not match, and Miele describes that as a technical fault an owner cannot remedy. It is not documented in the published coffee machine tables. The coffee range itself spans freestanding, countertop and built-in models with quite different hardware, including machines with a removable brew unit and machines where the brew unit is fixed and serviced only from inside, so even a confirmed code can imply a different repair depending on which you own. Treat any cross-appliance code chart with suspicion, and get the fault list for your own model and serial number.

When to stop and call someone

Call Miele service as soon as a full power-down and a careful reseat of every removable part have failed to clear it, which on an undefined code is sooner than you would escalate on a well documented one. There is no diagnostic you can usefully run at home against a code nobody publishes, and the machine's own internal fault log answers the question in minutes in a technician's hands. Call immediately rather than experimenting if you see or smell anything electrical, if water is appearing underneath the machine, or if it is a built-in model, since getting those out of a cabinet without damaging the furniture is a job in itself. If the machine was serviced recently, call that engineer first, because a configuration problem after a board replacement is their responsibility to put right.

Questions people ask

What does F43 mean on a Miele coffee machine?

Miele does not publish a definition for F43 in its coffee machine fault tables, and no reliable public source gives one. It is an internal fault the machine has logged rather than a maintenance prompt like descaling. The practical answer is to do a full power-down reset, reseat every removable part, and if it returns, have Miele read the machine's own fault log.

Can I fix F43 myself?

You can try the two things worth trying: a full power-down with the plug out for at least five minutes, and removing and refitting the water tank, drip tray, grounds container and brew unit so the machine can detect each one. Beyond that, no. Buying parts against an undefined code is how people spend real money and still have the fault.

Is F43 the same on a Miele coffee machine as on a Miele dryer?

Do not assume so. On Miele dryers, washers and ovens, F43 indicates the model type is not programmed or that two control modules do not match, which Miele treats as a technician-only fault. The coffee range uses the same F numbering for its own fault list, and the same number does not carry over between appliance types. Cross-appliance charts are where most bad F43 advice comes from.

Can I still use the machine with F43 showing?

Usually not, because the machine stops rather than brewing with a logged fault. If it does still make coffee between appearances of the code, you can keep using it while you arrange service, but empty the drip tray and grounds container more often than usual and watch underneath for water. An intermittent fault that involves the water circuit can turn into a leak.

Will descaling clear F43?

Almost certainly not. Descaling addresses a scaled-up water circuit, which Miele signals with its own prompts and its own codes, not with an undefined F4x. Run the descale if the machine has been asking for one, since an overdue descale causes its own problems, but do not expect it to clear this code and do not keep running descale cycles hoping it will.

Why did F43 appear right after my machine was serviced?

That timing is worth reporting to whoever did the work. On other Miele appliance lines, this code family means a replacement control module has not been programmed with the correct model type, which is the state a new board is in before it is configured. It has not been confirmed for coffee machines, but a recently serviced machine throwing a new electronics code is a conversation to have with that engineer first.

Is a Miele coffee machine worth repairing at this cost?

Usually yes. A service visit and repair in the $180 to $450 range sits against a replacement cost that is often four figures, and these machines routinely run well over a decade with the brew unit cleaned and the descaling kept up. Get the diagnosis and the quote before deciding, and ask whether the fault is in the brew unit or the electronics, because that changes the number.
