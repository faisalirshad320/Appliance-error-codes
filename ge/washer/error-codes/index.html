GE washer error codes: how to read them, including the flashing light patterns

Last reviewed 2026-10-16 · GE washer

What it means

GE washers report faults in three different ways depending on the model. Machines with a digital display show a number, usually somewhere between 1 and 99, or a short letter code. Machines with no display spell the same number out using the cycle status lights: each lit light carries a value, you add the lit values together, and the total is the fault number. The oldest top loaders just blink a single light a set number of times, so you count the blinks between pauses. In all three cases the control also stores a list of recent faults that you can read back in service mode, which is far more useful than whatever is on the panel right now.

Safety first

Unplug the washer at the wall before removing the control console, the top panel or the rear panel. The control board, the motor and the motor control all carry line voltage, and the motor control can hold a charge after the machine is unplugged.

Why a GE washer shows this code

These are the causes in the order you are most likely to hit them. Work down the list, do not skip to the expensive one.

  1. Drain faults: the machine asked for a pump-out and the water did not leave in timemost casesOpen the lid at the end of a cycle. Water standing above the bottom of the basket, or clothes that come out soaked rather than spun, means the code you are looking at is a drain code regardless of what number it is.
  2. Out-of-balance faults: the load bunched up and the basket could not reach spin speedmost casesThe machine filled and washed normally, then spent several minutes refilling, sloshing and retrying before it quit. One heavy item, a mat, or a single pair of jeans alone in the drum is the usual trigger.
  3. Lid lock or door lock faultscommonYou can hear the lock buzz or click repeatedly at the start of a cycle, or the machine never locks at all and stops before filling. On top loaders the lid strike is often just bent or the lock plunger is gummed up.
  4. Fill and water-level faultscommonThe cycle starts but the water either never arrives, arrives far too slowly, or keeps coming until the machine shuts itself off. Check both taps and both inlet screens before you blame the pressure sensor.
  5. Motor and motor control faultsoccasionalThe basket does not turn at all, or it grinds, hums and stops. On belt-drive machines look for a belt off its pulley. On direct-drive models, a basket that spins freely by hand but not under power points at the motor control.
  6. Control board, wiring harness and communication faultsrareThe code makes no physical sense: a drain fault with a dry tub, a lid fault with the lid clearly locked, or a code that changes every cycle. Inspect every connector for corrosion before condemning a board.

Fix it step by step

  1. Write down exactly what the panel is doing before you touch anything

    If you have a display, note the characters. If you have lights only, note which lights are lit and in what order, or count the blinks between pauses. Take a photo with your phone. The pattern often clears when you open the lid or press a button, and if you lose it you have to run the machine to failure again to get it back.

    3 minTools: Phone camera

  2. Find your model number and the tech sheet inside the machine

    The model number is on a label inside the lid on top loaders, or on the door frame on front loaders. GE ships a folded service tech sheet inside most machines, usually tucked into the control console, under the top panel, or behind the lower front panel. That sheet carries the code table for your exact model, which is the only table that is guaranteed to be right.

    10 minTools: Phillips #2 screwdriver

    Unplug the washer before opening the console or removing any panel to look for the tech sheet.

  3. Decode the light pattern into a number

    On a model with no display, the lit status lights are a binary number. Read them in order along the row, with each position worth double the one next to it: 1, 2, 4, 8, 16, 32. Add the values of the lit lights together and the total is the fault number. Four lights worth 1, 2, 4 and 8 lit together, for example, means fault 15. Which end of the row carries the 1 and which lights are used varies by model, so match the row on the tech sheet before you trust the total.

    5 min

  4. Put the washer into service mode and read the stored fault list

    Most GE washers hold the last several faults in memory and will play them back in order, most recent first. On many 27-inch top loaders you enter service mode by holding the Start button for about ten seconds, then turning the cycle knob to advance through the numbered tests; test 1 is the fault list. When the list ends, or when there are no stored faults, the machine flashes a pair of dashes. The exact entry sequence differs by model, so use the one printed on your tech sheet.

    10 min

    Exit service mode the way the tech sheet describes rather than pulling the plug mid-test.

  5. Rule out the three physical faults behind most codes

    Before you go near a part, do these. Pull the drain hose out of the standpipe and check it is not kinked or pushed down more than a few inches into the pipe. Open the drain pump filter if your model has one behind the lower front panel and clear the lint, coins and hair. Then rebalance the load by hand and run a spin-only cycle. These three account for a large share of the codes people search for.

    25 minTools: Phillips #2 screwdriver, shallow tray, towels

    Unplug the washer before opening the lower panel. Expect standing water if the machine failed to drain.

  6. Clear the stored codes and run a short cycle to see which one returns

    A stored fault list is a history, not a diagnosis. Half the codes in there may be from a one-off overload two years ago. Clear the list using the procedure on the tech sheet, then run a rinse-and-spin and read the list again. Whatever comes back is the live fault, and that is the one worth spending money on.

    15 min

  7. Power cycle the machine properly

    Unplug the washer at the wall, or switch off its breaker, and leave it off for five full minutes. The control holds residual charge and a quick off-and-on frequently does not clear a latched fault. Plug it back in and start a rinse-and-spin so you find out in three minutes instead of an hour.

    7 min

How to reset it

Press Start or Power to cancel, then unplug the washer at the wall or switch off its breaker for five full minutes. Plug it back in and start a rinse-and-spin. If the machine is in service mode, exit it the way the tech sheet describes before cutting power. Note that a power cycle clears the latched code on the display but does not clear the stored fault history, which has to be cleared from service mode.

It still shows the code

If you have decoded the pattern and the washer still will not run, work through it in this order rather than guessing at parts. First, decide which family the code belongs to from the symptom rather than the number, because GE reuses numbers across model families and a table you found for a different machine will send you the wrong way: no water out is a drain fault, no water in is a fill fault, a basket that will not turn is a motor or balance fault, and a machine that stops before filling is almost always a lid or door lock. Second, test the cheap end of that family. For a drain fault that means the hose, the standpipe, the filter and the pump impeller, which together cost nothing and clear most of them. For a balance fault it means leveling the machine with a spirit level across the top, since a washer that rocks on an uneven floor will throw a balance code with a perfectly normal load. For a lid fault it means the strike and the plunger. Third, if the cheap end is clean, the part is the next step: a lid lock assembly, a drain pump or a water-level pressure sensor are each in the $25 to $120 range and most are a half-hour job. Fourth, if the code points at the motor control or the main board, stop and price the repair against the machine. A control board plus a call-out on a washer over eight years old often costs more than half what a new one does. One more thing worth checking before you spend anything: if the same code appears on every cycle at exactly the same point, the fault is real and repeatable. If it appears at random points on random cycles, suspect a connector rather than a component, and go over every plug on the control and the motor for green corrosion or a pin that has backed out of its housing.

Differences between models

Three generations behave differently. Older Hydrowave top loaders have no display and signal with a single light blinking a count between pauses. Later top loaders and front loaders without a display use the binary status-light pattern described above. GTW and GFW machines with a digital display show the fault number or letter code directly and also hold a stored fault list in service mode. Numbers are not portable between these families: the same two-digit number can mean an out-of-balance spin on one machine and something unrelated on another, which is why the tech sheet for your exact model matters more than any list online.

When to stop and call someone

Call someone when the code points at the motor control or the main board, when the drain path is clear but the pump still will not run with the machine live, or when you would have to work inside the console with power on to go any further. That is live-voltage diagnosis and it is not worth a shock to save a call-out. Call sooner if the machine is leaking, if it smells of burning, or if the motor hums and will not turn, because running a stalled motor repeatedly can take the motor control with it. And before you authorize any board replacement on a machine over eight years old, ask for the part price up front and weigh it against a new washer.

Questions people ask

Where can I find the GE washer fault code list as a PDF?

The only list that is reliably correct for your machine is the tech sheet GE folded up and left inside it, usually in the control console or behind the lower front panel. GE also publishes technical service guides per model series. Generic PDFs that circulate online mix codes from several model families together, which is how people end up replacing the wrong part.

What does error code 26 mean on a GE washer?

On the 27-inch top loaders it is logged when an out-of-balance load ended the final spin, so the machine gave up trying to rebalance. Redistribute the load, level the machine, and run a spin-only cycle. Check it against your tech sheet first, because the same two-digit numbers carry different meanings across GE model families.

How do I read the flashing lights if my washer has no display?

Treat the lit lights as a binary number. Each light position is worth double the one next to it, running 1, 2, 4, 8, 16 and 32, and you add the values of the lit lights to get the fault number. The tech sheet inside your machine shows which lights are used and which end carries the value of 1.

Can I keep using the washer while a code is showing?

It depends on the family. A balance code is harmless and the machine will usually finish on a lower spin speed. A drain code is not: running cycle after cycle against a blocked drain can overheat the pump and leaves dirty water sitting in the tub. Stop using it for any code involving water that will not leave, a leak or a motor that hums.

Why did a code appear suddenly when nothing changed?

Most of these build slowly and then cross a threshold. A drain filter clogs over months, suspension rods wear gradually until one bad load trips a balance code, and a lid strike bends a fraction at a time. The genuinely sudden ones are a power cut, a tripped breaker, or something hard getting into the pump in one wash.

Does clearing the stored fault codes fix anything?

No, but it makes the next diagnosis honest. The stored list is a history going back a long way, and old entries from a single overload years ago will mislead you. Clear it, run a rinse-and-spin, and read it again. Only a code that comes back is worth spending money on.

Is a GE washer with a control board fault worth repairing?

Usually not past about eight years. A main control or motor control plus a technician's time commonly lands between $300 and $450 fitted, which is a large share of the price of a new machine. Under five years old, and especially if the rest of the machine is sound, it is normally worth doing.

My washer shows no code at all but will not start. What now?

Check power first: the outlet, the breaker, and whether the lid or door is actually latching. A machine that is completely dark has a supply or power-board problem rather than a fault code. If the panel lights up but nothing happens when you press Start, go into service mode and read the stored fault list, which will often name the fault the panel never displayed.
