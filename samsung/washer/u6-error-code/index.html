Samsung washer U6 error code: what it means and how to fix it

Last reviewed 2026-10-15 · Samsung washer

What it means

U6 on a Samsung washer points at a spin balance problem: the drum would not balance, so the machine would not spin it. It is worth saying plainly that U6 is poorly documented. It does not appear in Samsung's published washer code list, and a good share of the time what is on the display is actually Ub, the standard unbalanced load code, with the b read as a 6 on a small seven-segment panel. Either way the first moves are the same: redistribute the load by hand, then check the machine is level on all four feet.

Why a Samsung washer shows U6

These are the causes in the order you are most likely to hit them. Work down the list, do not skip to the expensive one.

  1. The code is actually Ub, the unbalanced load faultmost casesLook at the character straight on and in good light, ideally with a phone photo zoomed in. A lower-case b and a 6 are nearly the same shape on a seven-segment display. If the top of the character is open rather than closed, it is a b. Either reading leads to the same checks, so this costs you nothing to establish.
  2. One heavy item, or a load tangled into a single massmost casesOpen the door. A soaked bath mat, hoodie or duvet cover sitting in a lump on one side with everything else flat against the drum wall. Wet, that one item outweighs the whole rest of the wash and the drum cannot be balanced around it.
  3. The machine is not level, or the feet have worked loosecommonPush each top corner down in turn. If the machine rocks on a diagonal, two feet are carrying it and two are not. Check each lock nut as well: a correctly set foot will unwind itself over a year or two of spinning if the nut was never tightened against the cabinet.
  4. Worn shock absorbers or suspension rodscommonThe code appears on every load including small mixed ones, with a knock from inside the cabinet at spin-up. Push the empty drum down sharply by hand: one controlled drop is healthy, two or three rebounds means the damping is gone.
  5. The floor flexes under the machineoccasionalStand beside it during spin-up. If the floor moves under your feet or a glass rattles on a nearby counter, the machine is feeding its own vibration into a suspended timber floor and the sensor reads it as imbalance.
  6. A code specific to your model that does not match the general caserareYour machine's own code list, in the user manual or on the service sheet inside the cabinet, shows U6 as something unrelated to balance. Because this code is not well documented across the range, your model's own list beats any general guide including this one.

Fix it step by step

  1. Photograph the display and zoom in

    Take a close photo of the code with your phone and enlarge it. You are checking whether the second character is a 6 or a lower-case b, because Ub is the standard Samsung unbalanced load code and the two look almost identical on a seven-segment panel. Knowing which you have makes every search you do afterwards more accurate.

    3 min

  2. Check your model's own code list

    Find the model number on the sticker inside the door opening or on the back of the cabinet, then look up that exact model's code list in the user manual or on the service sheet tucked inside the machine. For a poorly documented code this is worth more than any general guide, and it takes a few minutes.

    10 min

  3. Redistribute the load by hand

    Pause the cycle and wait for the drum to stop so the door releases. Pull everything out, shake each item loose and untwist anything that has roped together. Put it back spread evenly around the drum rather than dropped in as one lump, then run Spin or Rinse and Spin. This clears most balance codes on its own.

    8 min

    Wait for the drum to come to a complete stop before reaching in.

  4. Run an empty spin

    Take everything out and run Spin only on a completely empty drum. An empty machine has nothing to unbalance, so this cleanly separates a loading problem from a machine problem. Smooth and quiet to full speed means the machine is fine. The same code on an empty drum means the fault is mechanical and you can stop rearranging laundry.

    12 min

  5. Level the machine and lock the feet

    Put a spirit level across the top both ways, push each corner down to find the rocking diagonal, and adjust the feet until the cabinet sits solid everywhere. Then hold each foot and tighten its lock nut firmly against the underside of the cabinet with a wrench. Check the drain hose is not trapped behind a foot, which quietly lifts one corner off the floor.

    20 minTools: Adjustable wrench, spirit level

  6. Bounce test the suspension

    With the machine empty and switched off, grip the top edge of the drum, push it down firmly and let go. A healthy front loader drops and stops in one controlled movement. Two or three rebounds means the shock absorbers have lost their damping, or on a top loader that the suspension rods are spent.

    6 min

How to reset it

Press Power to cancel, unplug the washer at the wall for a full five minutes, then plug it back in. Redistribute the load by hand before restarting, and use Spin or Rinse and Spin rather than a full wash so you see within a couple of minutes whether the drum now balances. A reset on its own does nothing if the laundry is still bunched to one side.

It still shows U6

Because U6 is not a well-documented code, the most useful thing you can do before spending money is pin down what your particular machine means by it. Find the model number on the sticker inside the door opening and look up that model's own code list in the manual or on the service sheet inside the cabinet, and if that list disagrees with this page, believe the list. Assuming it is the balance fault the evidence points to, work in order of cost. First the free checks: level the machine on all four corners while it is loaded and wet rather than empty, tighten every lock nut, free the drain hose from behind any foot, and feel whether the floor itself moves during spin-up. A front loader on a springy timber floor throws balance codes it would never throw on concrete, and plywood screwed across the joists underneath is the cheapest genuine fix there is. Second, clean the pump debris filter, because a machine that drains slowly leaves water sloshing in the outer drum and that imitates an unbalanced load exactly. Third, the suspension: a pair of dampers for a front loader is $30 to $90 and a couple of hours with the front panel off, while a top loader's four suspension rods cost more and must go in as a complete set or the imbalance just moves to another corner. Fourth, listen during spin-up with the drum empty: a knock is suspension, while a rumble that rises and falls with drum speed is bearings, and on an older machine that is where repair stops being worth it. If the code survives all of this and your model's own documentation does not explain it, get a technician who can read the machine's stored fault history rather than guessing from the display, because that is the one thing you cannot do from the outside.

Differences between models

U6 is not listed in Samsung's general washer code documentation, and third-party sources disagree about it: most treat it as an unbalanced load, a few describe it as a door-open condition, and several point out that it is frequently a misread Ub. That disagreement is itself the honest answer, and it is why this page leads with checking the character on the display and your own model's code list. If your panel really does show Ub, use the UB page, which covers the same ground with no ambiguity. If it shows a door code such as dC or dE instead, that is a different circuit entirely.

When to stop and call someone

Call someone if the code survives an empty spin on a properly levelled machine, or if your model's own code list does not list U6 at all and you have run out of things to check from the outside. A technician can read the machine's stored fault history and see what the control actually recorded, which is the one piece of information a display will not give you and the main reason a call-out is worth paying for on an ambiguous code. Call sooner if the machine bangs hard enough during spin to walk across the floor, since running it like that damages the tub and bearings. Ask for the diagnosis in writing before agreeing to any part, because on a code this poorly documented it is easy to be sold a guess.

Questions people ask

What does U6 mean on a Samsung washer?

In practice it points at a spin balance problem: the drum would not balance so the machine stopped. It is worth being honest that U6 is not in Samsung's published washer code list, and sources disagree about it. Most treat it as an unbalanced load, which matches what owners actually find, and the balance checks are cheap enough to be worth doing first.

Is U6 actually the Ub code?

Very often, yes. On a seven-segment display a lower-case b and a 6 are almost the same shape, and Ub is Samsung's standard unbalanced load code. Take a close photo and zoom in to check. It barely matters for the fix, since both lead to the same checks, but knowing which you have makes any further research far more reliable.

Can I still use the washer showing U6?

You can wash, but you are unlikely to get a proper spin, so clothes come out wet. There is no safety risk in running it, though a machine that bangs hard during spin is steadily damaging its own suspension and bearings. Redistribute the load and run a spin again rather than accepting cycle after cycle that ends soaking.

How do I find out what my specific model means by U6?

Get the model number from the sticker inside the door opening or on the back of the cabinet, then check that model's code list in the user manual or on the service sheet folded inside the machine. For a code this poorly documented, your model's own list is worth more than any general guide, including this one.

Does U6 mean I need new shock absorbers?

Not as a first conclusion. Worn dampers do cause persistent balance codes, but so does one heavy towel in a small load, which is much more common. Run a spin on a completely empty drum. If that is smooth and quiet, the suspension is fine and the problem is loading. If the code appears on an empty drum, then look at the dampers.

Why do different websites give different meanings for U6?

Because Samsung does not document it in its general washer code list, so sites are filling the gap with inference. Most settle on unbalanced load, a few say door open, and several note it is a misread Ub. Treat any confident single answer with suspicion and go by your own model's documentation and the empty spin test.
